PROPERTY RISK, VALUE & OPTIONS MAP

A Civic Flow Chart research tool for understanding what exists before deciding what should happen next

Core question: Before asking “What should we build?”, ask: “What exactly are we inheriting, what does it cost to keep it, what does it cost to change it, what value does it already provide, who carries each risk, and which choices become harder afterward?”

This is a public working tool. It is not a property appraisal, legal opinion, engineering report, environmental assessment, or government determination. Its job is to organize questions and evidence so that different people can inspect the same problem.

How to use it: Load an example or enter your information → click 1. Prepare Research Document → review the generated research record → click 2. Print / Save as PDF. The AI prompt can be copied separately when you want an AI research assistant to investigate the questions.

2. The research method

Listen → Record → Verify → Ask → Understand → Compare → Decide

Keep these categories separate:

  • Reported: someone says this is true.
  • Documented: a source records it.
  • Verified: the source was opened and actually supports the statement.
  • Estimate: a calculation or professional judgment that may change.
  • Interpretation: a reasonable reading that is not itself a primary fact.
  • Disputed / unresolved: evidence or interpretations differ, or the answer is not yet established.

Finding a source is not the same thing as checking the source.

13. Why this example exists

This tool grew out of a Civic Flow Chart test involving 1214 Soquel Avenue in Santa Cruz. The purpose of the test was not to decide the project's outcome. It was to ask whether the same research method used to investigate a complicated contracting/property problem could help residents, property owners, developers, public agencies, and other participants understand the same underlying system.

The test asks a simple systems question:

When different people have different interests in the same property, can we map the facts, risks, values, authorities, costs, time, and remaining choices without requiring everyone to agree?

The framework is portable. A different person can use this page for a different parcel, project, neighborhood, public facility, or redevelopment question.
